# Security Policy

## Supported Versions

The latest release of each API in this repository is supported with security updates. Older versions may not receive fixes.

## Reporting a Vulnerability

If you discover a security vulnerability in any of the APIs or services in this repository, please report it privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**.

Please do not open a public issue for security vulnerabilities, and do not disclose the details publicly until a fix has been released.

You can expect an initial response within 7 days. If the report is accepted, a fix will be prepared and released as soon as reasonably possible, and credit will be given to the reporter in the release notes unless anonymity is requested.
