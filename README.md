## Featured API: AI Email Writer API

Write ready-to-send emails with AI: generate complete new emails from a short topic, draft polished replies to emails you received, and brainstorm subject lines that get opened. You control the tone and the length, in English and Indonesian — no blank-page staring, no awkward phrasing.

**Live on RapidAPI → [AI Email Writer API](https://rapidapi.com/Hitler-HlDevZDwP/api/ai-email-writer-api)**

### What it does

Give the API a topic (for a new email), the original message (for a reply), or a topic plus a count (for subject lines), and it returns finished, ready-to-send text generated by a large language model. Pick a tone — `professional`, `friendly`, `formal`, `casual`, or `persuasive` — and a language — `en` or `id` — and the output follows it.

| | |
|---|---|
| Input | A short `topic` (for `/write` and `/subject`) or the full `original` email text (for `/reply`), plus optional tone, language, and length controls |
| Output | JSON — `subject` and `body` for `/write` and `/reply`; a `subjects` array for `/subject` |
| Latency | 5–20 seconds per call (LLM generation — a 60-second client timeout is recommended) |
| Endpoints | `GET\|POST /write`, `GET\|POST /reply`, `GET\|POST /subject`, `GET /health` |

### Quick start

#### cURL

```bash
# Write a new email from a topic (GET with query parameters)
curl "https://ai-email-writer-api.p.rapidapi.com/write?topic=Follow%20up%20on%20a%20job%20application&tone=professional&language=en" \
  -H "X-RapidAPI-Key: YOUR_API_KEY" \
  -H "X-RapidAPI-Host: ai-email-writer-api.p.rapidapi.com"

# The same call as POST with a JSON body
curl -X POST "https://ai-email-writer-api.p.rapidapi.com/write" \
  -H "X-RapidAPI-Key: YOUR_API_KEY" \
  -H "X-RapidAPI-Host: ai-email-writer-api.p.rapidapi.com" \
  -H "Content-Type: application/json" \
  -d "{\"topic\": \"Follow up on a job application\", \"tone\": \"professional\", \"language\": \"en\"}"
```

**Response:**

```json
{
  "subject": "Following up on my job application",
  "body": "Dear Hiring Manager,\n\nI hope you are doing well. I am writing to follow up on my recent job application and to reiterate my strong interest in the position. I believe my skills and experience would be a great fit for your team, and I would welcome the opportunity to discuss how I can contribute.\n\nPlease let me know if you need any additional information from me. I am available for an interview at your convenience.\n\nThank you for your time and consideration.\n\nBest regards",
  "tone": "professional",
  "language": "en"
}
```

Every endpoint accepts **GET** (query parameters) or **POST** (JSON body with the same field names). Full details are in [`docs/ai-email-writer.md`](docs/ai-email-writer.md).

### API reference

#### `GET|POST /write`

Write a complete new email — subject and body — from a topic.

| Parameter | Required | Notes |
|---|---|---|
| `topic` | yes | What the email is about, e.g. `Follow up on a job application` |
| `tone` | no | `professional` (default), `friendly`, `formal`, `casual`, `persuasive` |
| `language` | no | `en` (default) or `id` |
| `recipient_name` | no | Greets this person, e.g. `Sarah` |
| `sender_name` | no | Signs off with this name, e.g. `David` |
| `length` | no | `short` (~60 words), `medium` (default, ~130 words), `long` (~230 words) |

#### `GET|POST /reply`

Draft a reply to an email you received. The response has the same shape as `/write` — `subject` (usually `Re: ...`), `body`, `tone`, `language`.

| Parameter | Required | Notes |
|---|---|---|
| `original` | yes | The full text of the email you are replying to |
| `intent` | no | What your reply should say, e.g. `Accept the price of USD 1,250 including shipping, confirm delivery in 5-7 business days` |
| `tone` | no | Same tones as `/write` (default `professional`) |
| `language` | no | `en` (default) or `id` |

#### `GET|POST /subject`

Generate subject-line ideas for a topic. The response is a JSON object with a `subjects` array.

| Parameter | Required | Notes |
|---|---|---|
| `topic` | yes | What the email is about |
| `count` | no | How many ideas: default 5, maximum 10 |
| `tone` | no | Same tones as `/write` (default `professional`) |
| `language` | no | `en` (default) or `id` |

#### `GET /health`

Returns `{"status": "ok"}` when the service is up.
